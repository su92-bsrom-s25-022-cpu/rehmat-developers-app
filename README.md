# Rehmat Developers Flutter App

A starter Flutter Android app for Rehmat Developers.

## Included
- Dark navy and cyan branding
- Home, Services, About and Contact tabs
- Company services and team details from the current website
- WhatsApp inquiry, email and official website actions

## Build the APK
1. Install Flutter SDK and Android Studio.
2. Extract this project.
3. Open a terminal in the project folder.
4. Run `flutter pub get`.
5. Run `flutter build apk --release`.
6. Find the APK at `build/app/outputs/flutter-apk/app-release.apk`.

## Notes
- The app uses the company contact details currently shown on the website.
- Portfolio projects and pricing are not hard-coded because the website is still being developed.
- Replace the temporary code icon in `BrandHeader` with the official logo when its image file is ready.
